This repository is set for the 2026-2027 string theory seminar named *Reading Strings* in PKU. It contains seminar schedule, a long Q&A reference and their Tex source.

- [`Basic_Concepts_of_String_Theory_28_Week_Seminar_Plan.pdf`](Basic_Concepts_of_String_Theory_28_Week_Seminar_Plan.pdf): Seminar plan
- [`basic_concepts_string_theory_reading_companion.pdf`](basic_concepts_string_theory_reading_companion.pdf): Q&A reference
- [`texsource/`](texsource/): TeX source

An important task of this seminar is to collect questions commonly raised in reading string theory and typically the book *Basic Concepts of String Theory*. The Q&A reference contains questions collected in this seminar and in participants' personal reading. The answers are generated by AI, mostly by GPT-5.6-sol. If you have any question which is not presented in this Q&A reference, please send it to me and I will update to this Q&A reference.
